# Spinberth site

Landing, privacy and support pages for **Spinberth**, a 3D bump-and-clear puzzle for iPhone (coming soon to the App
Store). Served by GitHub Pages from `main`: https://nguyenvanlamm.github.io/spinberth-site/

- `index.html` — landing page
- `privacy.html` — App Store privacy policy URL
- `support.html` — App Store support URL

Images in `assets/` are rendered from the game itself (app icon, in-game screens).
